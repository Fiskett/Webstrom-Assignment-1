Development of Web Based Applications (1ik163)

Included in the course

Kursens syfte är att introducera studenten i utveckling av webbapplikationer, vilket innebär förståelse för och användning av både klient- och servertekniker. Studenterna ska förstå vad som görs på vilken sida (klient eller server) och varför. För serversidan ska antingen en lokal applikationsserver sättas upp eller så ska studenterna använda existerande serversidetjänster. Slutligen ska ett projekt genomföras där en extern databas används för att lagra data som behövs i webbapplikationen. Undervisningsformer Undervisningen består av föreläsningar, seminarier och övningar. Laborationsuppgifterna löses enskilt. Projektarbetet ska utföras i grupp. Examination Kursen bedöms med betygen Underkänd, Godkänd eller Väl godkänd. Bedömning av prestationer sker genom redovisning av obligatoriska övningar både i skriftlig rapporter och genom presentationer. Laborationer kan ges betyget U eller G. Projektet kan ge betyget U, G eller VG. Kursen avslutas med ett obligatoriskt projekt och en skriftlig tentamen. Betyget VG ges när minst en av projekt eller tentamen har VG och den andra delen minst G. Förnyad examination ges i enlighet med Lokala regler för kurs och examination på grundnivå och avancerad nivå vid Linnéuniversitetet.Om universitetet beslutat att en student har rätt till särskilt pedagogiskt stöd på grund av funktionsnedsättning, har examinator rätt att ge ett anpassat prov eller att studenten genomför provet på ett alternativt sätt. Kursvärdering

HTML (HyperText Markup Language) provides the fundamental structure of a webpage by defining elements such as headings, paragraphs, lists, images, and links, giving the browser a clear description of how the content is organized. CSS (Cascading Style Sheets) works together with HTML by controlling how these elements should look, allowing developers to set colors, fonts, spacing, layouts, and responsive behavior for different screen sizes. When combined, HTML delivers the content itself while CSS shapes its visual presentation, resulting in webpages that are both readable and visually consistent across different devices.
