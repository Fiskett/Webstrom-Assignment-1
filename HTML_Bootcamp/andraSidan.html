Development of Web-Based Applications (1IK163)

Included in the Course

The purpose of the course is to introduce students to the development of web applications, which involves understanding and using both client-side and server-side technologies. Students are expected to understand what is carried out on the client side and what is handled on the server side, as well as the reasons behind these choices. On the server side, either a local application server should be set up or existing server-side services should be used. The course culminates in a project where an external database is employed to store the data required by the web application. Teaching is conducted through lectures, seminars, and exercises, with laboratory assignments completed individually and project work carried out in groups. The course is graded as Fail, Pass, or Pass with Distinction, and assessment is based on mandatory exercises presented both in written reports and oral presentations. Laboratory assignments can be graded as Fail or Pass, while the project can be graded as Fail, Pass, or Pass with Distinction. The course concludes with a mandatory project and a written examination, and the grade Pass with Distinction is awarded when at least one of the project or the exam is graded Pass with Distinction and the other part at least Pass. Re-examination is conducted in accordance with the Local Rules for Courses and Examinations at undergraduate and advanced levels at Linnaeus University. If the university has decided that a student is entitled to special educational support due to a disability, the examiner has the right to provide an adapted examination or allow the student to complete the examination in an alternative way. The course also includes a course evaluation.

HTML (HyperText Markup Language) provides the fundamental structure of a webpage by defining elements such as headings, paragraphs, lists, images, and links, giving the browser a clear description of how the content is organized. CSS (Cascading Style Sheets) works together with HTML by controlling how these elements should look, allowing developers to set colors, fonts, spacing, layouts, and responsive behavior for different screen sizes. When combined, HTML delivers the content itself while CSS shapes its visual presentation, resulting in webpages that are both readable and visually consistent across different devices.
